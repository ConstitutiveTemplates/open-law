Jurisdiction coverage map — channel status per adapter and probe¶

Probe date: 2026-10-11 · Method: robots.txt + one endpoint probe each, politely (single spaced requests, open-law-probe/1.0 UA). Status is evidence-based, not aspirational; re-probe before acting on a row. The charter (CHARTER.md) governs every row: robots.txt is law, a 403 challenge means denied, and an API that exists but is robots-disallowed stays off-limits. Asia rows live in asia-coverage.md; this file covers the adapters added after it (Germany, US states) plus the jp/kr re-probes.

Status legend¶

Same marks as asia-coverage.md: ✅ shipped · 🔑 needs a free registration/key · 🤖 bot-challenged — denied means denied · 🚫 robots-disallowed · 🧩 SPA shell / no machine channel · 📄 reachable but scrape-only/unverified · 🔌 unreachable · ❓ unprobed.

How to extend this map¶

Same probing protocol as asia-coverage.md: robots.txt first, then one endpoint probe, spaced ≥2 s — record the HTTP code in the table above. A new US state follows the us-tx pattern (static file host + key-free JSON API behind the site's JS bundle) with source id us-<postal>; a blocked site gets a table row here, not an adapter.
